This page collects learning resources for scientific computing. Several chapters keep their own resource lists, so this page points to those lists rather than repeating them:

  • R Coding Practices: Additional Resources - books on R, R packages, Shiny, and Git for R users
  • R Coding Practices: Tidyverse - tidy evaluation and programming with {dplyr}
  • Continuous Integration - CI services and tools for R packages
  • Quarto - Quarto documentation, templates, and {litedown}
  • Git and GitHub - GitHub Learn, the UC Davis DataLab Git sandbox, and graphical Git clients
  • Unix - shell tools and The Missing CS Quarter at UC Davis

1 Resources for R

  • Awesome R Package Development Tools - curated list of tools for R package development
  • Tidyverse style guide - the style guide behind R Code Style
  • Hadley Wickham’s R Style Guide - the style chapter of the first edition of Advanced R
  • Tidyverse data-dict - open specification and CLI tool for creating, validating, and documenting data dictionaries in YAML format

1.1 UC Davis DataLab workshops and tutorials

The UC Davis DataLab provides workshops and learning materials for data science:

  • Workshop Index - catalog of all DataLab workshops
  • R Basics Workshop - foundational R programming for beginners
  • Research Toolkits - guides for research tools and methods
  • Install Guides - setup instructions for data science software

1.2 Cheat sheets

  • Data transformation with dplyr cheat sheet
  • Data tidying with tidyr cheat sheet
  • Data visualization with ggplot2 cheat sheet
  • data.table cheat sheet
  • R Markdown cheat sheet

2 Resources for Git and GitHub

  • GitHub Skills: Introduction to GitHub - an interactive exercise, under an hour long, on branches, commits, and pull requests

3 Resources for Python

  • UC Davis DataLab Python Basics Workshop - foundational Python programming
  • Natural Language Processing with Python - text analysis and NLP techniques
  • Jupyter Notebooks in a Git Repository - guide by Matthias Geier on managing Jupyter notebooks in Git repositories, including workflows for stripping cell outputs before committing and strategies for sharing executed notebooks

4 Resources for Julia

  • UC Davis Julia Users Group Julia Basics Workshop - foundational Julia programming

5 Open science and reproducibility

  • The Open Science Manual - an open-source guide from the ARCA group at the University of Padova covering programming good practices, version control, and reproducible workflow tools.
  • Openscapes - an open science mentorship and community initiative founded by Dr. Julia Stewart Lowndes, focused on helping research groups transition to data-intensive, reproducible, and collaborative scientific practices through cohort-based Champions programs and shared open tooling.

[]{#sec-resources}

This page collects learning resources for scientific computing.
Several chapters keep their own resource lists,
so this page points to those lists rather than repeating them:

- [R Coding Practices: Additional Resources](coding-practices.qmd#sec-r-resources) -
  books on R, R packages, Shiny, and Git for R users
- [R Coding Practices: Tidyverse](coding-practices.qmd#sec-tidyverse) -
  tidy evaluation and programming with `{dplyr}`
- [Continuous Integration](continuous-integration.qmd#sec-r-ci) -
  CI services and tools for R packages
- [Quarto](quarto.qmd) -
  Quarto documentation, templates, and `{litedown}`
- [Git and GitHub](github.qmd#sec-github) -
  GitHub Learn, the UC Davis DataLab Git sandbox, and graphical Git clients
- [Unix](unix.qmd#sec-unix) -
  shell tools and The Missing CS Quarter at UC Davis

## Resources for R {#sec-resources-r}

- [Awesome R Package Development Tools](https://github.com/IndrajeetPatil/awesome-r-pkgtools) -
  curated list of tools for R package development
- [Tidyverse style guide](https://style.tidyverse.org/) -
  the style guide behind [R Code Style](coding-style.qmd)
- [Hadley Wickham's R Style Guide](http://adv-r.had.co.nz/Style.html) -
  the style chapter of the first edition of *Advanced R*
- [Tidyverse data-dict](https://data-dict.tidyverse.org/) -
  open specification and CLI tool for creating, validating, and documenting
  data dictionaries in YAML format

### UC Davis DataLab workshops and tutorials

The [UC Davis DataLab](https://github.com/ucdavisdatalab) provides workshops and learning materials for data science:

- [Workshop Index](https://ucdavisdatalab.github.io/workshop_index/) - catalog of all DataLab workshops
- [R Basics Workshop](https://github.com/ucdavisdatalab/workshop_r_basics) - foundational R programming for beginners
- [Research Toolkits](https://github.com/ucdavisdatalab/research-toolkits) - guides for research tools and methods
- [Install Guides](https://ucdavisdatalab.github.io/install_guides/) - setup instructions for data science software

### Cheat sheets

- [Data transformation with dplyr cheat sheet](https://rstudio.github.io/cheatsheets/html/data-transformation.html)
- [Data tidying with tidyr cheat sheet](https://rstudio.github.io/cheatsheets/html/tidyr.html)
- [Data visualization with ggplot2 cheat sheet](https://rstudio.github.io/cheatsheets/html/data-visualization.html)
- [data.table cheat sheet](https://s3.amazonaws.com/assets.datacamp.com/blog_assets/datatable_Cheat_Sheet_R.pdf)
- [R Markdown cheat sheet](https://rstudio.github.io/cheatsheets/html/rmarkdown.html)

## Resources for Git and GitHub {#sec-resources-git}

- [GitHub Skills: Introduction to GitHub](https://github.com/skills/introduction-to-github) -
  an interactive exercise, under an hour long,
  on branches, commits, and pull requests

## Resources for Python {#sec-resources-python}

- [UC Davis DataLab Python Basics Workshop](https://github.com/ucdavisdatalab/workshop_python_basics) - foundational Python programming
- [Natural Language Processing with Python](https://github.com/ucdavisdatalab/workshop_nlp_with_python) - text analysis and NLP techniques
- [Jupyter Notebooks in a Git Repository](https://mgeier.github.io/git-jupyter.html) -
  guide by Matthias Geier on managing Jupyter notebooks in Git repositories,
  including workflows for stripping cell outputs before committing
  and strategies for sharing executed notebooks

## Resources for Julia {#sec-resources-julia}

- [UC Davis Julia Users Group Julia Basics Workshop](https://ucjug.github.io/workshop_julia_basics/) - foundational Julia programming

## Open science and reproducibility {#sec-resources-open-science}

- [The Open Science Manual](https://arca-dpss.github.io/manual-open-science/) -
  an open-source guide from the [ARCA group](https://github.com/arca-dpss) at the University of Padova
  covering programming good practices,
  version control,
  and reproducible workflow tools.
- [Openscapes](https://openscapes.org/) -
  an open science mentorship and community initiative founded by Dr. Julia Stewart Lowndes,
  focused on helping research groups transition to data-intensive, reproducible,
  and collaborative scientific practices through cohort-based Champions programs
  and shared open tooling.
