This page collects learning resources for scientific computing. Several chapters keep their own resource lists, so this page points to those lists rather than repeating them:

- [R Coding Practices: Additional Resources](../chapters/coding-practices.llms.md#sec-r-resources) - books on R, R packages, Shiny, and Git for R users
- [R Coding Practices: Tidyverse](../chapters/coding-practices.llms.md#sec-tidyverse) - tidy evaluation and programming with `{dplyr}`
- [Continuous Integration](../chapters/continuous-integration.llms.md#sec-r-ci) - CI services and tools for R packages
- [Quarto](../chapters/quarto.llms.md) - Quarto documentation, templates, and `{litedown}`
- [Git and GitHub](../chapters/github.llms.md#sec-github) - GitHub Learn, the UC Davis DataLab Git sandbox, and graphical Git clients
- [Unix](../chapters/unix.llms.md#sec-unix) - shell tools and The Missing CS Quarter at UC Davis

## 1 Resources for R

- [Awesome R Package Development Tools](https://github.com/IndrajeetPatil/awesome-r-pkgtools) - curated list of tools for R package development
- [Tidyverse style guide](https://style.tidyverse.org/) - the style guide behind [R Code Style](../chapters/coding-style.llms.md)
- [Hadley Wickham’s R Style Guide](http://adv-r.had.co.nz/Style.html) - the style chapter of the first edition of *Advanced R*
- [Tidyverse data-dict](https://data-dict.tidyverse.org/) - open specification and CLI tool for creating, validating, and documenting data dictionaries in YAML format

### 1.1 UC Davis DataLab workshops and tutorials

The [UC Davis DataLab](https://github.com/ucdavisdatalab) provides workshops and learning materials for data science:

- [Workshop Index](https://ucdavisdatalab.github.io/workshop_index/) - catalog of all DataLab workshops
- [R Basics Workshop](https://github.com/ucdavisdatalab/workshop_r_basics) - foundational R programming for beginners
- [Research Toolkits](https://github.com/ucdavisdatalab/research-toolkits) - guides for research tools and methods
- [Install Guides](https://ucdavisdatalab.github.io/install_guides/) - setup instructions for data science software

## 2 Resources for Git and GitHub

- [GitHub Skills: Introduction to GitHub](https://github.com/skills/introduction-to-github) - an interactive exercise, under an hour long, on branches, commits, and pull requests

## 3 Resources for Python

- [UC Davis DataLab Python Basics Workshop](https://github.com/ucdavisdatalab/workshop_python_basics) - foundational Python programming
- [Natural Language Processing with Python](https://github.com/ucdavisdatalab/workshop_nlp_with_python) - text analysis and NLP techniques
- [Jupyter Notebooks in a Git Repository](https://mgeier.github.io/git-jupyter.html) - guide by Matthias Geier on managing Jupyter notebooks in Git repositories, including workflows for stripping cell outputs before committing and strategies for sharing executed notebooks

## 4 Resources for Julia

- [UC Davis Julia Users Group Julia Basics Workshop](https://ucjug.github.io/workshop_julia_basics/) - foundational Julia programming

## 5 Open science and reproducibility

- [The Open Science Manual](https://arca-dpss.github.io/manual-open-science/) - an open-source guide from the [ARCA group](https://github.com/arca-dpss) at the University of Padova covering programming good practices, version control, and reproducible workflow tools.
- [Openscapes](https://openscapes.org/) - an open science mentorship and community initiative founded by Dr. Julia Stewart Lowndes, focused on helping research groups transition to data-intensive, reproducible, and collaborative scientific practices through cohort-based Champions programs and shared open tooling.
